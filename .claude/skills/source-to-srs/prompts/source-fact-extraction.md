# 源码事实抽取 Prompt

## 角色

你负责在已确认 scope 内，从源码抽取可支撑 SRS 的事实。你的输出是事实层，不是最终 SRS。

## 输入

```text
source_project:
target_module:
scope-confirmation.md:
entry_files:
```

## 输出

```text
source-facts.md
```

必须覆盖六类事实：

1. 功能点
2. 字段规则
3. 业务规则
4. 权限规则
5. 异常处理
6. 验收要点

## 抽取规则

### 1. 功能点

对每个候选功能记录：

```text
功能名称：
接口 / 入口：
请求对象：
响应对象：
主要 Service：
权限码：
错误码：
```

### 2. 字段规则

从 DTO / VO / Entity / Service 抽取：

- 必填
- 类型
- 长度
- 格式
- 枚举
- 默认值
- 唯一性
- 可为空性
- 导入导出字段

### 3. 业务规则

从 Service / Mapper / SQL 抽取：

- 创建校验
- 更新校验
- 删除限制
- 状态变更规则
- 批量操作规则
- 导入导出规则
- 跨实体关联规则

### 4. 权限规则

从权限注解、权限码、菜单初始化数据抽取：

- 功能权限码
- 权限与接口的对应关系
- 特殊无需权限入口
- 权限缺失风险项

### 5. 异常处理

从 ErrorCode、异常抛出位置、校验方法抽取：

- 错误码
- 错误信息
- 触发条件
- 关联功能

### 6. 验收要点

验收要点只能来自：

- 功能入口行为
- 字段规则
- 业务规则
- 权限规则
- 异常处理

不得编造验收标准。若为合理推导，标记为 `derived_from_source`。

```markdown

- 响应对象：

```

## 禁止事项

- 不要写最终需求文档。
- 不要补充源码中不存在的业务规则。
- 不要把猜测写成 high confidence。
- 不要忽略低置信度项。

## 失败条件

- scope 未确认。
- 核心入口文件无法读取。
- 核心功能无法找到源码依据。
