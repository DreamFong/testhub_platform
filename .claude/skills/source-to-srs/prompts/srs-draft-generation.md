# SRS 事实草稿生成 Prompt

## 角色

你负责根据 `source-facts.md` 生成事实导向的 SRS 草稿。该草稿用于后续改写，不是最终交付文档。

## 输入

```text
scope-confirmation.md
source-facts.md
source-evidence-map.md 可选
```

## 输出

```text
srs-factual-draft.md
```

## 目标

事实草稿优先：

- 完整性
- 源码准确性
- 可追溯性
- 风险显式化

事实草稿不优先：

- 最终文风
- 历史 SRS 风格
- PDF 排版

## 结构

```markdown
# {模块名称} SRS 事实草稿

## 1. 模块范围

### 1.1 纳入范围

### 1.2 排除范围

### 1.3 相邻依赖

## 2. 功能事实

### FR-{MODULE}-{NNN} {功能名称}

- 功能类型：
- 入口：
- 输入：
- 输出：
- 权限：
- 主要规则：
- 异常：
- 源码依据：

## 3. 字段事实

## 4. 业务规则事实

## 5. 权限事实

## 6. 异常事实

## 7. 验收要点草稿

## 8. 不确定项与风险
```

## 要求

- 每个功能点需要源码依据。
- 不确定项必须进入“不确定项与风险”。
- 不得把低置信度推断写成确定需求。
- 不得新增 source facts 中没有的功能。
- 验收要点必须能回到功能、字段、业务、权限或异常规则。

## 失败条件

- source facts 缺少核心功能。
- 多个核心功能无源码依据。
- 草稿无法支撑后续正式 SRS。
