# Skill A：评分表规范

版本：v0.1  
适用范围：Skill A 自评、独立评审和人工复核

## 1. 总体模型

Skill A 使用 5 个维度评分，每项 5 分，总分 25 分：

1. 功能覆盖度
2. 源码准确度
3. 规则完整度
4. 需求表达质量
5. 知识库友好度

评分结果必须同时检查硬性不合格项。若命中硬性不合格项，即使总分较高也应判定为 fail。

## 2. 功能覆盖度

| 分数 | 标准 |
|---:|---|
| 5 | 核心功能、边界功能、明确排除项均完整明确。 |
| 4 | 核心功能完整，少量边界功能描述不足。 |
| 3 | 核心功能基本覆盖，但存在明显遗漏。 |
| 2 | 多个核心功能缺失，或误纳入多个相邻模块能力。 |
| 1 | 模块范围严重错误，文档不可作为目标模块 SRS。 |

检查清单：

- 是否覆盖 scope confirmation 的最终纳入范围。
- 是否遗漏导入导出、批量操作、状态流转等边界能力。
- 是否明确排除相邻能力。
- 是否把相邻依赖误写成核心功能。

## 3. 源码准确度

| 分数 | 标准 |
|---:|---|
| 5 | 需求与源码事实高度一致，关键结论均有 evidence 支撑。 |
| 4 | 存在轻微表述偏差，但不影响理解。 |
| 3 | 存在部分误读或依据不足，但核心规则未写反。 |
| 2 | 多个规则与源码不一致。 |
| 1 | 大量编造或关键规则写反。 |

检查清单：

- SRS 中的功能是否来自源码入口。
- 字段规则是否来自 DTO / VO / Entity / Service。
- 权限规则是否来自注解、权限码或配置。
- 异常规则是否来自错误码和抛出逻辑。
- 是否误用 reference_srs 覆盖源码事实。

## 4. 规则完整度

| 分数 | 标准 |
|---:|---|
| 5 | 字段、业务、权限、异常、验收规则完整。 |
| 4 | 主要规则完整，少量边界规则不足。 |
| 3 | 规则基本可用，但存在明显缺口。 |
| 2 | 多类关键规则缺失。 |
| 1 | 规则层严重缺失，仅有功能列表。 |

检查清单：

- 字段必填、格式、长度、枚举、默认值、唯一性是否覆盖。
- 业务校验、状态变更、删除限制是否覆盖。
- 权限规则是否覆盖。
- 异常处理是否覆盖。
- 验收标准是否覆盖正常、异常和边界路径。

## 5. 需求表达质量

| 分数 | 标准 |
|---:|---|
| 5 | 符合 SRS 风格，结构清晰，业务视角明确，非研发读者可直接理解。 |
| 4 | 整体符合需求文档表达，少量段落偏源码说明，但不影响主体理解。 |
| 3 | 可读但源码笔记感明显，存在一定技术细节污染。 |
| 2 | 大量堆砌实现细节，难以作为需求文档。 |
| 1 | 文档结构混乱或不可读。 |

检查清单：

- 是否使用业务能力表达。
- 非研发读者是否可以直接理解主要功能、规则、异常和验收标准。
- 是否夹带过多实现术语，例如注解、类名、方法名、接口路径、权限码。
- FR 编号是否稳定。
- 功能需求是否有清晰目标和规则。
- 验收标准是否可执行。
- 排除项是否明确。

## 6. 知识库友好度

| 分数 | 标准 |
|---:|---|
| 5 | 标题稳定、连续段落友好、低表格依赖、PDF 文本层可提取且人类可读。 |
| 4 | 整体适合知识库，少量表格、标题或 PDF 可读性问题。 |
| 3 | 可进入知识库候选，但存在 chunk、检索或 PDF 阅读风险。 |
| 2 | 结构问题明显，关键规则可能难以检索，或 PDF 可读性明显不足。 |
| 1 | PDF 或文本结构不可用。 |

检查清单：

- 标题层级是否稳定。
- FR 编号是否可检索。
- 字段规则、异常处理、验收标准是否避免复杂表格。
- PDF 文本层是否可提取。
- PDF 标题是否不重复、标题层级是否清晰。
- PDF 中英文混排是否正常，英文项目名、类名、接口路径、权限码和 FR 编号是否没有异常拆字。
- PDF 页边距、行距、段落间距和整体风格是否满足人类可读性要求。
- 关键检索关键词是否出现在正文中。

## 7. 硬性不合格项

任一命中即推荐 fail：

1. 编造源码中不存在的需求、字段、权限或流程。
2. 核心功能缺失。
3. 关键规则写反。
4. 文档结构不可用。
5. PDF 文本层不可提取。
6. PDF 可读性 gate fail，例如标题重复、英文异常拆字、明显乱码、页面截断或排版不可读。
7. 关键结论无法提供源码依据。

## 8. 输出格式

评分输出必须包含：

```text
function_coverage: /5
source_accuracy: /5
rule_completeness: /5
requirement_expression_quality: /5
kb_friendliness: /5
total: /25
hard_fail_items:
  - 
gate: pass | conditional pass | fail
required_fixes:
  - 
recommended_improvements:
  - 
requires_manual_review: true | false
```
