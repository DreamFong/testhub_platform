# Scope Inference

## 候选范围

- 盘点任务主单：创建、修改、删除、提交、完成、取消、查询、导出。
- 盘点任务行：自动生成、手工新增/修改/删除、分页与精简列表查询、盘盈盘亏状态计算。
- 盘点结果：新增、修改、删除、分页与详情查询，以及结果与任务行之间的联动。

## 本轮确认范围

本轮范围确认为“MES 盘点任务模块”，覆盖盘点任务、盘点任务行、盘点结果，以及由盘点结果驱动的盘盈/盘亏/正常差异判定和库存冻结/解冻行为。

## 范围边界

- 盘点方案、物料库存、仓库主数据、用户主数据仅作为依赖来源，不展开其独立需求。
- 不延伸到盘点差异落账、库存调整单生成、财务处理或审批流引擎实现。
- 不进入 Skill B / Skill C 与下游知识库流程。
