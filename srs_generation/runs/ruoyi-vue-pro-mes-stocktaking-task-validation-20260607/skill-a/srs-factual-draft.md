# RuoYi-Vue-Pro MES 盘点任务模块事实草稿

## 文档概述

本文档基于 MES 盘点任务相关 controller、service、VO、枚举和错误码整理模块事实，覆盖盘点任务、盘点任务行、盘点结果以及盘盈盘亏状态判定。

## 功能范围

- 盘点任务创建、修改、删除、提交、完成、取消、分页、详情、导出。
- 盘点任务行自动生成、手工维护、分页、详情、精简列表。
- 盘点结果新增、修改、删除、分页、详情。
- 盘点差异通过任务行状态表达。

## 核心事实

### FR-STOCKTAKING-001 盘点任务维护

系统支持创建、修改、删除、查询和导出盘点任务。任务创建时校验任务编码唯一、盘点人有效、盘点方案可用；创建后默认状态为草稿。修改和删除仅允许在草稿状态执行。若任务绑定盘点方案，则创建和修改时会生成或重建任务行。

### FR-STOCKTAKING-002 盘点任务提交流转

任务提交前必须已存在任务行。提交成功后任务状态改为审批中；当任务开启冻结标识时，提交同时冻结关联库存。任务完成仅允许在审批中状态执行，完成后状态改为已完成，并在需要时解冻库存。任务取消不允许作用于已完成或已取消任务，取消后状态改为已取消，并在需要时解冻库存。

### FR-STOCKTAKING-003 盘点任务行生成与维护

盘点任务行可从盘点方案自动生成，也可在草稿状态手工新增、修改和删除。自动生成时会先基于方案参数筛选库存；动态盘点必须具备开始和结束时间。若没有可盘库存，则不生成任务行。自动生成的任务行默认盘点数量为 0，初始状态为盘亏，后续由盘点数量与账面数量比较结果刷新为盘盈、盘亏或正常。

### FR-STOCKTAKING-004 盘点结果录入与回退

盘点结果的新增、修改、删除均要求任务处于审批中状态。新增结果时，若未指定任务行，系统会尝试按任务、物料和库位范围匹配已有任务行；若没有匹配项，则补建一条账面数量为 0 的任务行。录入或修改盘点结果后，会刷新对应任务行的盘点数量和状态。删除盘点结果时，会回退对应任务行的盘点数量。

### FR-STOCKTAKING-005 盘点差异判定

当盘点数量大于账面数量时，任务行应被判定为盘盈；当盘点数量小于账面数量时，应判定为盘亏；当两者相等时，应判定为正常。若盘点结果补建了账面数量为 0 的任务行，则正数盘点数量会直接表现为盘盈。

## 风险提示

删除盘点结果时，源码通过向任务行写入原盘点数量的相反数来回退盘点数量，但任务行更新逻辑本身使用覆盖式更新，而非基于旧值累加回退。因此，“count 正负数在差异处理中的业务口径”无法在当前源码中被完全业务化确认，应作为显式风险保留，不能在正文中被写死为确定规则。
