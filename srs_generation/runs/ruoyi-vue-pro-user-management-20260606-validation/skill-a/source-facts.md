# Source Facts

## 功能事实

1. 系统支持分页查询用户，可按账号、手机号、状态、创建时间、部门、角色筛选。
2. 系统支持按编号查询单个用户详情，并在返回时补充部门信息。
3. 系统支持获取精简用户列表，主要用于前端选择场景。
4. 系统支持新增用户；新增时校验租户账号配额、唯一性、部门和岗位有效性。
5. 系统支持修改用户；通用修改流程不会更新密码。
6. 系统支持删除单个用户与批量删除用户；删除后清理权限关联和岗位关联。
7. 系统支持单独重置用户密码。
8. 系统支持修改用户状态；当状态改为禁用时会使该用户后台访问令牌失效。
9. 系统支持导出用户数据，导出筛选条件与分页查询一致。
10. 系统支持下载用户导入模板。
11. 系统支持导入用户；导入时逐行校验并返回创建成功、更新成功和失败结果。

## 字段与校验事实

- 用户账号：必填，仅允许数字和字母，长度 4-30，且必须唯一。
- 用户昵称：长度不超过 30。
- 邮箱：格式合法，长度不超过 50，且必须唯一。
- 手机号：格式合法，且必须唯一。
- 创建密码：新增必填，长度 4-16。
- 重置密码：用户编号必填，新密码必填，长度 4-16。
- 状态修改：用户编号和状态必填，状态必须来自通用状态字典。
- 导入模板字段：登录名称、用户名称、部门编号、用户邮箱、手机号码、用户性别、账号状态。

## 业务规则事实

- 新增用户前必须检查租户账号配额。
- 新增和修改用户前必须校验用户名、手机号、邮箱唯一性。
- 新增和修改用户前必须校验部门和岗位有效。
- 修改用户时不通过通用保存入口更新密码。
- 删除用户后清理权限关联和岗位关联。
- 批量删除用户时逐个清理关联数据。
- 用户禁用后，已发放的后台访问令牌失效。
- 导入时若列表为空则失败；若初始化密码缺失则失败。

## 异常事实

- 用户账号已存在
- 手机号已存在
- 邮箱已存在
- 用户不存在
- 导入列表为空
- 初始化密码为空
- 超出租户账号配额
