# Skill C 执行约束增强任务清单

## 目标

从真实跑通案例、接口调用结果和 TestHub 执行经验中提炼执行约束，补充纯 SRS 不包含但自动化闭环需要的规则。

## 1. 职责边界

- [ ] 定义 Skill C 负责提炼执行约束
- [ ] 定义 Skill C 负责补充认证与 token 规则
- [ ] 定义 Skill C 负责补充实体 ID 提取规则
- [ ] 定义 Skill C 负责补充最小请求 body 规则
- [ ] 定义 Skill C 负责补充必带 headers
- [ ] 定义 Skill C 负责补充错误字段黑名单
- [ ] 明确 Skill C 不负责生成 SRS
- [ ] 明确 Skill C 不负责 RAGFlow chunk 评估

完成标准：Skill C 被定义为执行增强层，而不是需求文档层。

## 2. 输入契约

- [ ] 定义输入 Skill A 最终 SRS
- [ ] 定义输入 Skill B 知识库结果
- [ ] 定义输入真实跑通接口案例
- [ ] 定义输入 TestHub 执行日志或失败记录
- [ ] 定义输入认证方式说明
- [ ] 定义输入实体创建 / 查询 / 更新样例

完成标准：Skill C 能从运行事实中提炼可执行规则。

## 3. 认证与 token 规则

- [ ] 提炼登录接口路径
- [ ] 提炼登录请求 body
- [ ] 提炼 token 响应字段路径
- [ ] 提炼 Authorization header 格式
- [ ] 提炼 token 过期或刷新规则
- [ ] 记录认证失败常见原因

完成标准：TestHub 能根据约束完成认证前置步骤。

## 4. 实体 ID 提取规则

- [ ] 提炼创建接口响应中的 ID 路径
- [ ] 提炼列表查询中的 ID 路径
- [ ] 提炼详情接口中的 ID 路径
- [ ] 提炼 update/delete 依赖的 ID 来源
- [ ] 提炼 userId / entityId 等字段命名差异
- [ ] 记录错误 ID 路径黑名单

完成标准：自动化流程能稳定串联 create → query/update/delete。

## 5. 最小请求 body 规则

- [ ] 提炼创建接口最小必填字段
- [ ] 提炼更新接口最小必填字段
- [ ] 提炼导入类接口最小文件或字段要求
- [ ] 提炼字段默认值策略
- [ ] 提炼不能发送的冗余字段
- [ ] 提炼容易导致失败的错误字段组合

完成标准：TestHub 生成的请求 body 不再依赖猜测。

## 6. Headers 与环境变量规则

- [ ] 提炼 Content-Type 要求
- [ ] 提炼 Authorization 要求
- [ ] 提炼 tenant-id 或类似租户字段要求
- [ ] 提炼环境 base_url 要求
- [ ] 提炼 cookies 或 csrf 等特殊要求
- [ ] 记录 headers 缺失导致的典型失败

完成标准：执行环境配置可以被自动化复用。

## 7. 错误字段与路径黑名单

- [ ] 记录不得使用的字段名
- [ ] 记录不得使用的响应路径
- [ ] 记录错误的 ID 提取方式
- [ ] 记录错误的 token 提取方式
- [ ] 记录错误的请求 body 模板
- [ ] 记录会导致误执行的路径或方法

完成标准：约束增强层能显式避免已知错误。

## 8. 输出契约

- [ ] 输出执行约束增强 Markdown
- [ ] 输出认证规则片段
- [ ] 输出 ID 提取规则片段
- [ ] 输出最小 body 模板
- [ ] 输出 headers 模板
- [ ] 输出错误黑名单
- [ ] 输出最小闭环模板
- [ ] 输出 handoff 给总编排 Skill 的结构化摘要

完成标准：Skill C 的输出能直接增强 TestHub 自动化执行成功率。
