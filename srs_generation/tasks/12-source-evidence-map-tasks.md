# Source Evidence Map 任务清单

## 目标

定义并实现 `source_evidence_map`，确保 Skill A 生成的 SRS 中关键需求、规则和结论都能追溯到源码依据。

## 1. 结构设计

- [x] 定义 evidence map 文件格式
- [x] 定义功能需求 evidence 结构
- [x] 定义字段规则 evidence 结构
- [x] 定义业务规则 evidence 结构
- [x] 定义权限规则 evidence 结构
- [x] 定义异常处理 evidence 结构
- [x] 定义验收标准 evidence 结构

完成标准：evidence map 覆盖 SRS 的主要内容类型。

## 2. 功能需求映射

- [x] 为每个 FR 编号记录源码文件
- [x] 为每个 FR 编号记录类名或方法名
- [x] 为每个 FR 编号记录接口路径或路由
- [x] 为每个 FR 编号记录主要 service 逻辑
- [x] 为每个 FR 编号记录相关 DTO / VO

完成标准：每个主要功能需求都能回到源码位置。

## 3. 字段规则映射

- [x] 记录字段来源 DTO / VO
- [x] 记录字段来源 Entity / DO
- [x] 记录字段校验注解
- [x] 记录字段默认值来源
- [x] 记录字段唯一性来源
- [x] 记录字段枚举来源

完成标准：字段规则不是凭经验补写。

## 4. 业务规则映射

- [x] 记录 service 层校验逻辑
- [x] 记录跨实体校验逻辑
- [x] 记录状态变更逻辑
- [x] 记录删除限制逻辑
- [x] 记录导入导出处理逻辑
- [x] 记录事务或批量处理逻辑

完成标准：业务规则可被独立评审 Agent 复核。

## 5. 权限规则映射

- [x] 记录权限注解位置
- [x] 记录权限码
- [x] 记录角色或菜单初始化来源
- [x] 记录无需权限或特殊权限的例外
- [x] 记录权限与功能需求的对应关系

完成标准：权限需求不靠猜测。

## 6. 异常处理映射

- [x] 记录错误码常量
- [x] 记录错误信息
- [x] 记录抛出异常的位置
- [x] 记录触发条件
- [x] 记录与功能需求的对应关系

完成标准：异常规则能回溯到错误码和触发逻辑。

## 7. Evidence 质量检查

- [x] 检查是否存在无依据 FR
- [x] 检查是否存在无依据字段规则
- [x] 检查是否存在无依据权限规则
- [x] 检查是否存在无依据异常规则
- [x] 检查是否存在 evidence 与 SRS 内容不一致
- [x] 记录无法确认的风险项

完成标准：关键结论无法提供源码依据时触发 fail 或人工复核。
