# PDF 生成与文本层检查任务清单

## 目标

定义 Skill A 中 Markdown → PDF 生成与基础可用性检查流程，确保 PDF 可以作为 Skill B 的可靠输入。

## 1. Markdown 输入规范

- [x] 定义 Markdown 标题层级要求
- [x] 定义 FR 编号格式要求
- [x] 定义列表格式要求
- [x] 定义表格使用限制
- [x] 定义中文字体兼容要求
- [x] 定义代码块或引用块使用限制

完成标准：Markdown 源文档适合稳定转换为 PDF。

## 2. PDF 生成脚本

- [x] 决定是否抽象现有生成脚本
- [x] 设计通用 Markdown→PDF 脚本参数
- [x] 支持输入 Markdown 路径
- [x] 支持输出 PDF 路径
- [x] 支持标题与元数据配置
- [x] 支持中文字体配置
- [x] 支持错误退出码

完成标准：不同 SRS 文档可以复用同一个 PDF 生成流程。

## 3. 文本层提取检查

- [x] 定义文本提取工具
- [x] 检查 PDF 是否能提取非空文本
- [x] 检查中文内容是否正常提取
- [x] 检查标题是否出现在提取文本中
- [x] 检查 FR 编号是否出现在提取文本中
- [x] 检查关键字段规则是否出现在提取文本中
- [x] 检查关键异常规则是否出现在提取文本中

完成标准：PDF 不是图片化或不可检索文档。

- [x] 定义文本长度输出

## 5. 失败处理

- [x] 定义 PDF 生成失败处理方式
- [x] 定义文本层不可提取处理方式
